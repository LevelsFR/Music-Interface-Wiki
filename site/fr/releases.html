Music Interface

Notes de version

La dernière version publique vérifiée est Music Interface v2.0, publiée le 28 septembre 2026 sur CurseForge.

v2.0 : fonctionnalités documentées

  • File d'attente avec Play Next, Add to Queue, réorganisation et sauvegarde facultative.
  • Track Radio basée sur les métadonnées et les préférences d'écoute locales.
  • Smart Mixes : For You, On Repeat, Rediscover, Current Context.
  • Profil local d'écoute et statistiques.
  • Règles de contextes pour biomes, météo, temps, dimensions et combats Cobblemon compatibles.
  • Diagnostic des Music Packs et génération de modèle.

Cette liste présente les fonctions vérifiées dans la documentation du code v2.0. Elle ne prétend pas que toutes étaient absentes des versions précédentes.
