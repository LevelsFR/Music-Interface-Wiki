Frequently asked questions

Does Music Interface come with music? Where do I download tracks?

No songs or ready-made music library are included. You must create or obtain a separate Music Pack (a Minecraft resource pack with OGG audio and track metadata). These packs may be made by you or shared by modpack/server creators. There is no built-in music catalog or automatic download service. See Music Packs for the full setup.

Why can't I find any songs, including Minecraft's vanilla soundtrack?

The Music Interface library displays custom tracks declared by active Music Packs. Vanilla Minecraft music is handled by Minecraft's own music system and does not appear automatically as Music Interface tracks. If you only installed the mod, an empty library is expected. Check that a valid pack is enabled, then reload with F3+T.

Is Music Interface a Cobblemon mod? Can I use it without Cobblemon or with an older Cobblemon version?

Music Interface is independent of Cobblemon. Ordinary music playback works without Cobblemon, as long as you install the correct Minecraft/loader build and a Music Pack. Cobblemon is an optional integration for battle detection; its battle features depend on the versions and integration hooks available. Having an older Cobblemon release does not make Cobblemon a required dependency for the player.

Does Music Interface work with Constant Music or other music mods?

Music Interface does not automatically read another mod's track list or resource files. Other mods may also manage Minecraft's MUSIC sound channel, so universal compatibility is not guaranteed. Music Interface has playback controls for vanilla/external music and a strictExclusiveMusic option to avoid starting music over another active soundtrack. If tracks overlap or interrupt one another, review both mods' music settings or let only one mod manage automatic music. You still need a Music Pack for Music Interface tracks.

What are moods, and do they control when songs play?

moods describe the atmosphere of a track, for example calm, relaxing or intense. Along with genres, tags and energy, they help Track Radio and Smart Mixes find related songs. Moods and tags are not event triggers. A song tagged battle is not automatically played during a battle.

How can I assign music to the menu, exploration or Cobblemon battles? Do I need Minecraft predicates?

No vanilla Minecraft predicates are required. Use the contexts rules in a track's music_data.json, or put them in music_contexts.json. Rules can match dimension, biome, biome tags, day/night, weather and Cobblemon combat. Example: "combat": true with a priority selects a battle track when the Cobblemon battle mode is set to context. The menu is handled separately by the Title-screen track ID setting. See examples for both files.

Can I change the Now Playing toast outline color?

The accent color is generated automatically from each track's cover art, with a default fallback if no usable cover exists. You can change the cover in your Music Pack, but Music Interface 2.0 has no manual outline-color setting.

Can a resource-pack lang file translate music titles?

The mod interface itself supports language files, but custom track names in music_data.json are currently plain display strings. The title value is displayed as written, not resolved as a translation key from assets/.../lang/*.json. Automatic per-language music title translation is not supported in 2.0. Authors should supply a readable title, or offer separate translated metadata packs where appropriate.

The generated template appears in the list, but its example track is silent. Why?

The template is a starting structure: it provides an example track definition, a sound event and cover, but not the example_track.ogg audio file. Add a real OGG file at the referenced path or replace the example with your song, then reload resources.
