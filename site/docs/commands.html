Client-side commands, diagnostics and permission-protected server music controls.

Commands and multiplayer

Distinguish client-local commands from administrator commands. A local player command does not imply that every multiplayer server allows the same literal syntax.

Client-side commands

CommandWhere definedPurpose
/musicinterface_diagnosticsFabric and NeoForge clientsShow loaded Music Pack counts, duplicate IDs, warnings and menu music state
/musicinterface_open_resourcepacksFabric and NeoForge clientsOpen the resourcepacks folder
/musicinterface_import_playlist <code>Fabric and NeoForge clientsImport a playlist share code
/musicinterface_import_shared <token>Fabric and NeoForge clientsImport a pending shared playlist token
/musicguiFabric client registrationOpen the player
/musicinterfaceNeoForge client registrationOpen the player
/musicinterface diagnosticsNeoForge client registrationShow local diagnostics

Client aliases can conflict with server command names in some setups. The local diagnostics alias is usually the clearest way to inspect a Music Pack.

Dedicated / integrated server command tree

These commands are registered on the server side with permission level 2. They require the relevant server installation; some actions also require compatible Music Interface clients.

CommandPurpose
/musicinterfaceRequest that the executing player's GUI opens
/musicguiGUI alias
/musicinterface diagnosticsRequest client diagnostics
/musicinterface listList server-visible song IDs
/musicinterface search <text>Search server-visible song IDs
/musicinterface play <id> <targets>Request playback for selected players
/musicinterface stop <targets>Request a stop
/musicinterface stop <targets> fadeRequest a fade-out stop

For example, /musicinterface play route_01 @a sends the track request to all eligible players, if the server knows route_01 and those clients have the corresponding music resource. The command does not transmit the OGG file. In single-player and multiplayer, permission and command registration may differ.
