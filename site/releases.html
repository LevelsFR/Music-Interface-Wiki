Release notes

The latest public release checked is Music Interface v2.0, published on September 28, 2026 on CurseForge.

v2.0: documented capabilities

  • Manual queue with Play Next, Add to Queue, reordering and optional persistence.
  • Track Radio driven by track metadata and private listening preferences.
  • Four Smart Mixes: For You, On Repeat, Rediscover and Current Context.
  • Local listening profile and statistics.
  • Context rules for biomes, weather, time, dimensions and optional Cobblemon battles.
  • Music Pack diagnostics and template generation.

These are capabilities verified in the v2.0 source documentation, not a claim that each was entirely absent from v1.9.
