Music Interface release notes

Verified published changelogs for the last two public releases, with links to the original CurseForge file pages. These are user-visible differences, not unreleased development plans.

Music Interface v2.0 September 28, 2026

New

  • Minecraft support: 1.21.4, 1.21.5, 1.21.8, 1.21.10, 1.21.11, 26.1, 26.2 and 26.3 are added as Fabric/NeoForge targets, alongside 1.21.1. Select the matching published file.
  • Manual Queue: Play Next, Add to Queue, ordering and saving the queue as a playlist, with optional persistence.
  • Track actions and Radio: track-specific actions for playing, organizing favorites and playlists, queueing and starting Radio.
  • Made for You: For You, On Repeat, Rediscover and Current Context mixes.
  • Listening Profile: local play counts, listening time, skips and listening statistics.
  • Context-aware selection: rules for dimensions, biomes, time, weather and compatible battles.
  • Richer track metadata: volume, cooldown, fade, genres, moods and tags.
  • Autoplay modes: Ambient and Continuous.

Changes

  • Menu selection: a blank Title-screen track ID now lets the player choose from the compatible library. In v1.9, blank disabled custom menu autoplay.
  • Cobblemon: battle audio can remain external or be handled with Music Interface's context rules.
  • Music Packs: tracks can include richer context rules and recommendation metadata.

Official v2.0 release notes on CurseForge

Music Interface v1.9 August 19, 2026

New

  • Fixed title-screen track ID setting to reserve a specific song for the menu.
  • Pack diagnostics with /musicinterface_diagnostics and /musicinterface diagnostics.

Changes

  • A blank title-screen ID disabled custom menu autoplay in v1.9. This behavior was changed again in v2.0.
  • Diagnostics reported pack counts, missing audio or covers, duplicate IDs and loading issues more clearly.

Fixes

  • Multiple active Music Packs could fail to merge properly.
  • Duplicate track IDs did not consistently obey resource-pack priority.
  • Malformed track definitions could block other valid packs.
  • Audio warnings could be misleading when OGG paths differed from event IDs.
  • Resource reload could retain stale track definitions.

Official v1.9 release notes on CurseForge

Download safely

Download only a JAR matching your actual Minecraft version and loader. A configured source target alone is not proof that a build is published or runtime-tested.
