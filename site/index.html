Music Interface Documentation for v2.0
Music Interface v2.0

Music Interface

Your music library, personalized playback and contextual soundtrack inside Minecraft.

Music for your Minecraft world.

Listen to songs from resource packs, build playlists, start Track Radio and let the scheduler react to biomes, weather and compatible Cobblemon battles. Start with installation or create a Music Pack.

At a glance

  • Complete library with favorites, artists, albums, playlists, search and a queue.
  • Radio and four personal Smart Mixes: For You, On Repeat, Rediscover and Current Context.
  • Menu, ambient, day/night, weather, dimension, biome and optional battle music.
  • Public Music Pack format; no Java development needed to add songs.

Using the music library

The player has a home library, search, grid/list display, Favorites, Albums, Artists, Playlists, History, Queue and Made for You.

  • Play a track: choose it in the library. The player offers play/pause, previous, next and stop controls.
  • Find a track: search or browse albums and authors. Use the home/favorites sorting controls where shown.
  • Favorite a track: use the favorite control. Favorites are saved locally and can be played as a collection, in order or shuffled.
  • Disable a track: use the track's available action. Disabled tracks are excluded from automatic selection. The library can optionally hide them.
  • Repeat: the repeat control cycles between Off, Playlist and Track.
  • Playlists: create, rename and delete playlists, manage their tracks and order, and play in order or shuffle.
  • History: displays a recent-track list with a configurable maximum size. This UI history is separate from the long-term listening statistics.

When a song starts, Music Interface can display a Now Playing toast with the cover, artist and album. The toast's outer border accent is derived automatically from the track cover's dominant color, with a built-in fallback color if no usable cover is available. Position, animation and displayed metadata are configurable; there is no separate setting for manually choosing the border color.

Playlists and sharing

The playlist view offers Copy share code, Import from clipboard and Share in chat actions. A share code contains a playlist name and track IDs, not audio files. The recipient therefore needs packs containing those song IDs for those entries to play. Client/server-supported sharing requires the appropriate Music Interface networking to be present.

Use the on-screen playlist controls for creation, editing and track management. A code import creates a local playlist; it does not download missing OGG files.

Queue, Radio and Made for You

Manual queue

Open a song's actions, then select:

  • Play Next: insert that song at the front of the pending manual queue.
  • Add to Queue: append it at the end.
  • Play Now: start it immediately instead of waiting for its queued turn.

The Queue screen lets you move songs up/down, drag to reorder, remove an entry, clear the queue, and Save as Playlist. The persistQueue setting controls whether the queue is saved to queue.json. It is enabled by default.

When the scheduler selects the next song, manual queue entries take precedence, followed by the active repeat/Radio/playlist flow and then normal autoplay as appropriate. Stop and manual playback actions can change the current playback source.

Track Radio

Open a song's actions and choose Start Radio. This keeps a starting song as the reference for choosing related tracks. Similarity considers:

  • shared tags, genres and moods;
  • artist, album and source Music Pack;
  • approximate energy level;
  • favorites and locally learned listening preferences.

Radio continues selecting tracks while active and candidates are available. Choose Stop Radio from the track action screen to return to the normal playback flow. Radio is not the same as context-triggered playback.

Made for You

Open Made for You in the player. It offers four automatically generated collections:

MixHow tracks are selected
For YouRanks tracks using favorites, listening history and shared metadata; starts with general choices if no habits exist
On RepeatTracks played most often
RediscoverPreviously played tracks whose last play was at least seven days ago
Current ContextTracks eligible for the current in-game situation, ordered with listening history as a preference

Each mix has Play and Shuffle actions. Collections evolve as your library, favorites, context and local profile change. They are not server-synced recommendations.

Listening profile

The profile presents total listening time, plays, favorites, tracks, top songs and habits such as artists, albums, packs, biomes, dimensions, time and weather. The data is stored locally. The source code does not synchronize it to a server or send telemetry.

The profile also provides separate reset actions for statistics, recommendations, and recent history. Be deliberate: a reset cannot be assumed reversible without a backup.

Cobblemon and CobbleSafari

These integrations are optional, client-side compatibility paths. Music Interface should remain functional without either mod.

  • Cobblemon: a compatible battle event toggles Music Interface's combat context. external mode suspends Music Interface's runtime for the battle; context mode allows the scheduler to use combat rules.
  • CobbleSafari: a compatibility bridge detects when CobbleSafari claims music playback, so Music Interface can coordinate music ownership rather than blindly overlapping it.

Availability depends on the installed companion mod, the Minecraft version and working integrations. Do not assume battle integration is available on every source target just because Music Interface itself builds.

Getting started

Installation

Install the correct Fabric or NeoForge build and set up your first music resource pack.

Choose the exact file for your setup.

The source contains 9 Minecraft targets and two loaders. A configured target is not proof that every feature was tested in-game on that exact combination. Use the official release listing to choose the correct version and loader.

Install and open the player

What you need

  • Minecraft: use one of the versions listed below, only if a compatible JAR has actually been released for it.
  • Loader: Fabric or NeoForge. Use the matching JAR, never both loaders' JARs together.
  • Java: Minecraft 1.21.x projects use Java 21; 26.x projects use Java 25.
  • Dependencies: install the matching loader dependencies. Do not mix dependency builds for different Minecraft versions.
  • Music Pack: required if you want to add your own songs; the mod itself does not provide your personal audio collection.
  1. Download the correct Music Interface JAR from CurseForge or Modrinth. Check the file's actual game version and loader.
  2. Install the dependencies shown on that file's release page and loader metadata.
  3. Place the JAR and dependency JARs in your Minecraft instance's mods/ directory.
  4. Launch the game. Open the Music Interface player using its assigned keybind or in-game UI entry point. Check Minecraft's Controls menu if you need to find or change the keybind.
  5. Enable a Music Pack from Minecraft's Resource Packs screen. The library is filled from active packs.

Settings screen: Music Interface integrates with Cloth Config, when installed and compatible. Without Cloth Config, the mod still loads, but the in-game settings screen is not available through that integration. Advanced users can edit config/musicinterface/config.json while the game is closed.

Playback and preferences

Configuration

Control title-screen music, automatic scheduling, contexts, fades, notifications and locally saved data.

Menu, ambient and contextual playback

Music Interface controls a custom playback scheduler. There are two complementary concepts:

  • Music metadata: genres, moods, tags and energy describe songs and assist Radio/Smart Mixes.
  • Music contexts: explicit rules in music_data.json or music_contexts.json tell the scheduler when a track is eligible. Supported conditions are dimension, biome, biome tag, day/night, weather and Cobblemon combat active/inactive.

For actual JSON and fully working examples, see the English Music Pack guide or the French guide.

Title screen

The customMenuMusicEnabled option enables Music Interface music on the title screen (enabled by default).

  • If Title-screen track ID is empty, eligible library songs can be selected automatically for the menu. Empty does not mean disabled.
  • If the ID contains an existing track ID, that track is reserved for custom title-screen autoplay and is excluded from world autoplay.
  • To stop custom title-screen music, switch Custom menu music off.
  • Allow vanilla menu music is separate and controls Minecraft's original menu soundtrack.
  • Title-screen autoplay uses the menu selection path; in-world context filters are not applied on the title screen.

Ambient versus Continuous

  • Ambient (default): the scheduler can leave a configurable gap between songs in a world.
  • Continuous: no intentional between-track delay.
  • World join silence: waits after entering a world before scheduled music starts; default is 10 seconds.

Context selection

  • A context rule matches when all its specified condition groups match. For a group accepting multiple values, any listed value may match.
  • More than one rule can be attached to a track. A matching rule makes the track eligible.
  • The scheduler selects from the highest matching numerical priority. Greater specificity alone does not raise priority.
  • If nothing matches, Library fallback (default) considers the normal available library, while Dedicated fallback restricts fallback to tracks marked context_fallback: true.
  • Finish (default) waits for the current track to finish after a context change. Crossfade can transition a track that the context scheduler started, when a different track is preferred.
  • A manually chosen track, queue item, playlist or Radio source does not become a forced battle cue just because a rule exists.
  • Track cooldown and disabled/failed tracks also affect automatic selection.

Cobblemon battles

Cobblemon integration is optional. The Cobblemon Battle Music setting defaults to External so Music Interface yields control while a recognized battle is active.

To let Music Interface select battle music:

  1. Install a compatible Cobblemon version for your Minecraft/loader, if one is available.
  2. In Music Interface settings, set Cobblemon Battle Music to Context (value context).
  3. Enable Context Music.
  4. Add tracks with a "combat": true context rule and an appropriate priority.
  5. To resume exploration music after battle, provide "combat": false rules or other eligible fallback tracks.
  6. If you want contextual music to switch during an already-playing contextual song, choose Crossfade instead of Finish.

A tag named battle alone does not create a battle event. Music Interface also supports an optional CobbleSafari music-coordination bridge; neither Cobblemon nor CobbleSafari is required for ordinary playback.

Resource pack creation

Music Packs

Step-by-step audio, JSON, cover art, moods, contexts and Cobblemon battle music examples.

Prefer French?

The complete Music Pack creation guide is also available in French.

A beginner-friendly guide to adding your own songs, cover art and music for specific situations in Minecraft.

Music Interface reads music from a standard Minecraft resource pack. You do not need to program a mod. The track metadata format works on Fabric and NeoForge, but vanilla resource-pack compatibility metadata must match the Minecraft version you use.

For the player, settings, queues, playlists and Radio, see the complete user guide.

Quick answers

  • Where are songs assigned to events? In a track's contexts field or optional music_contexts.json.
  • Are tags enough for battle music? No. tags, genres and moods describe songs for Radio and recommendations; they do not trigger events.
  • How do I pick one menu theme? Enter its song id in the Title-screen track ID setting. Blank allows automatic menu selection.
  • How does Cobblemon music work? Set Cobblemon Battle Music to Context and use a combat: true context rule.
  • Can I combine packs? Yes, including folders and ZIP files. Keep song IDs unique.

1. Create the pack folder

Open the folder of your Minecraft instance, then create My Music Pack inside its resourcepacks/ directory:

.minecraft/
└── resourcepacks/
    └── My Music Pack/
        ├── pack.mcmeta
        ├── pack.png                         (optional)
        └── assets/
            └── musicinterface/
                ├── music_data.json
                ├── music_contexts.json      (optional)
                ├── sounds.json
                ├── sounds/
                │   └── custom/
                │       ├── route_01.ogg
                │       └── battle_theme.ogg
                └── textures/
                    └── covers/
                        ├── route_01.png
                        └── battle_theme.png

Exact spelling matters. Music Interface reads the namespace assets/musicinterface/. Use lowercase names without spaces or accents for resource paths.

Easier option: generate a template

Open the Music Interface player and use its template generation control (hover for the tooltip). The mod creates resourcepacks/MusicInterface Template/ with folders, basic JSON and an example cover. It does not overwrite existing template files.

Replace the example track with your own OGG, then update its paths and IDs. The generated pack.mcmeta is a baseline example that may require changes for your Minecraft version.

2. Set up pack.mcmeta

Minecraft reads pack.mcmeta before enabling a resource pack. The project generator uses this for the Minecraft 1.21.1 baseline:

{
  "pack": {
    "pack_format": 34,
    "description": "My Music Pack for Music Interface"
  }
}

Do not copy pack_format: 34 blindly to 1.21.4, 1.21.11 or 26.x. Resource-pack metadata changes between Minecraft versions. Some versions also require different/additional format fields. Use the requirements for your exact Minecraft version. The music metadata documented below is independent of Fabric versus NeoForge.

If Minecraft reports that the pack is incompatible, fix pack.mcmeta first.

3. Add OGG files

Put your song here:

assets/musicinterface/sounds/custom/route_01.ogg

Use actual OGG audio, not an MP3 renamed to OGG. Short, consistent file names are easiest to manage.

4. Register sounds in sounds.json

Minecraft needs a sound event entry for each OGG. Save this file as assets/musicinterface/sounds.json:

{
  "custom/route_01": {
    "sounds": [
      {
        "name": "musicinterface:custom/route_01",
        "stream": true
      }
    ]
  },
  "custom/battle_theme": {
    "sounds": [
      {
        "name": "musicinterface:custom/battle_theme",
        "stream": true
      }
    ]
  }
}

The event musicinterface:custom/route_01 points to assets/musicinterface/sounds/custom/route_01.ogg. Omit the file extension and the sounds/ folder from the JSON name. Keep "stream": true for long music.

5. Register tracks in music_data.json

Save a JSON array inside assets/musicinterface/music_data.json. Here are two tracks:

[
  {
    "id": "route_01",
    "title": "Route 01",
    "author": "Your Name",
    "album": "Exploration",
    "sound": "musicinterface:custom/route_01",
    "cover": "musicinterface:textures/covers/route_01.png",
    "enabled": true,
    "weight": 1,
    "genres": ["ambient"],
    "moods": ["calm"],
    "tags": ["overworld", "exploration"],
    "energy": 0.3,
    "contexts": [
      {
        "combat": false,
        "priority": 10
      }
    ]
  },
  {
    "id": "battle_theme",
    "title": "Battle Theme",
    "author": "Your Name",
    "album": "Battles",
    "sound": "musicinterface:custom/battle_theme",
    "cover": "musicinterface:textures/covers/battle_theme.png",
    "enabled": true,
    "weight": 2,
    "genres": ["orchestral"],
    "moods": ["intense"],
    "tags": ["battle", "combat"],
    "energy": 0.9,
    "contexts": [
      {
        "combat": true,
        "priority": 100
      }
    ]
  }
]

route_01 can match when no battle is active; battle_theme can match while a compatible Cobblemon battle is active. You still need to enable Cobblemon's Context mode in settings, as explained below.

Use consistent labels, such as calm or orchestral, across your library to make Radio similarity useful. No fixed genre, mood or tag vocabulary is required.

Tags vs contexts

A tag answers "what kind of music is this?" A context answers "when can the scheduler choose it?"

{
  "tags": ["battle", "boss"],
  "contexts": [
    {
      "combat": true,
      "priority": 100
    }
  ]
}

This block shows fields within a track, not a standalone music_data.json file. Only contexts creates the battle condition; tags helps with similarity.

Context rule fields

FieldExampleBehavior
priority100Highest matching numeric priority wins; default 0
dimensions["minecraft:overworld"]Dimension identifiers
biomes["minecraft:plains"]Biome identifiers
biome_tags["#minecraft:is_forest"]Biome tag IDs; # prefix accepted
time["day"]day or night
weather["clear", "rain"]clear, rain or thunder
combattrueBoolean: supported Cobblemon combat active or inactive

For list properties, you may use a single string or an array. Multiple values in one property mean OR; different properties in one rule must all match (AND). Several rule objects represent alternative situations.

For example, this rule matches rain or thunder, at night, on plains in the Overworld, outside combat:

{
  "dimensions": ["minecraft:overworld"],
  "biomes": ["minecraft:plains"],
  "time": ["night"],
  "weather": ["rain", "thunder"],
  "combat": false,
  "priority": 30
}

Priority is explicit: a more specific rule is not automatically stronger than a general rule. A missing contexts rule does not restrict a song to any particular biome. Unrestricted/legacy songs can remain eligible during library fallback.

6. Ambient / exploration music

Put this property into an exploration track:

"contexts": [
  {
    "combat": false,
    "priority": 10
  }
]

To select forest music, add "biomes": ["minecraft:forest"] inside that rule. For time or weather, add time or weather.

Ambient is also a global playback mode: it can leave a delay between tracks. It is not a special tag or context value. Continuous removes the intentional delay.

7. Cobblemon battle music

For a song meant to play during a detected battle:

"contexts": [
  {
    "combat": true,
    "priority": 100
  }
]

Also configure the mod:

  1. Install compatible Cobblemon for the loader/game version, where available.
  2. Turn Context Music on in Music Interface.
  3. Set Cobblemon Battle Music to Context. Its default External mode suspends Music Interface music while a Cobblemon battle is detected.
  4. Select Context Transition: Crossfade if you want an already-playing context-managed song to change during context switches. Default Finish allows it to finish.
  5. Provide non-combat tracks, or a fallback library, for when battles end.

The integration observes supported Cobblemon battle events, not arbitrary Minecraft damage or other combat mods. A manual track, pending queue, Radio or playlist may take priority over context autoplay.

8. Title-screen music

A menu track is assigned through player settings, not by adding a menu tag:

  1. Add your menu song to music_data.json and sounds.json, with ID main_menu_theme.
  2. In Music Interface settings, enable Custom Menu Music.
  3. Set Title-screen track ID to main_menu_theme.

A blank title-screen track ID lets the mod choose automatically from the library on the title screen. To stop custom title-screen music, turn Custom Menu Music off. The Allow Vanilla Menu Music switch only controls Minecraft's own music. In-world context filtering is not applied to title-screen selection.

9. Optional music_contexts.json

If you prefer to keep context rules separate from song metadata, create assets/musicinterface/music_contexts.json. A JSON object keyed by track ID is supported:

{
  "route_01": [
    {
      "combat": false,
      "priority": 10
    },
    {
      "biomes": ["minecraft:forest"],
      "time": ["day"],
      "combat": false,
      "priority": 30
    }
  ],
  "battle_theme": [
    {
      "combat": true,
      "priority": 100
    }
  ]
}

An array of rules is also supported:

[
  {
    "track": "route_01",
    "combat": false,
    "priority": 10
  },
  {
    "track": "battle_theme",
    "combat": true,
    "priority": 100
  }
]

External rules are added to a track's inline rules. When multiple packs supply external rules for the same track ID, the higher-priority pack's external definition wins. A reference to an unknown track ID produces a warning.

For simple packs, choose either inline contexts or music_contexts.json, to avoid duplicating rules unintentionally.

10. Fallback when nothing matches

In Context Fallback settings, select:

  • Library (default): choose from available tracks if no explicit context matches.
  • Dedicated: choose only songs marked "context_fallback": true if no rule matches.

Example single track for the music_data.json array:

{
  "id": "route_01",
  "title": "Route 01",
  "sound": "musicinterface:custom/route_01",
  "context_fallback": true,
  "contexts": [
    {
      "combat": false,
      "priority": 10
    }
  ]
}

11. Covers, pack priority and reload

Place covers under assets/musicinterface/textures/covers/ and reference them by resource ID:

"cover": "musicinterface:textures/covers/route_01.png"

Toast colors: the Now Playing toast automatically samples its border accent from the track's cover artwork. If no usable cover is available, it uses a built-in fallback accent. There is no setting or Music Pack JSON field for choosing an arbitrary outline color.

Enable the folder or ZIP pack in Minecraft's Resource Packs menu. After editing, press F3+T. Music Interface rebuilds the track list from active packs; it does not accumulate old definitions.

When two packs define the same id, the higher-priority pack wins. Prefer stable, unique IDs: playlists and favorites store these IDs.

Use the local /musicinterface_diagnostics client command to see active packs, duplicate IDs, missing audio events, missing covers and parse warnings. NeoForge also registers /musicinterface diagnostics locally; a server command with the same name may require administrator permissions.
